Author, acknowledgements and scope
==================================

Author and maintainer
---------------------

**Thibaut Jacqmin** is eLabmate's original author and maintainer. The project
started from his laboratory code and requirements. Subsequent improvements,
tests and documentation were developed with AI-assisted coding support under
his direction. That assistance does not replace the project's authorship or
alter the repository's actual contribution history.

The existing repository licence and copyright notices remain authoritative.
This documentation does not assign a different licence or claim ownership
of third-party software. Retain the licence file and attribution when
redistributing the project.

Dependencies and acknowledgements
---------------------------------

* `eLabFTW <https://www.elabftw.net/>`_ provides the electronic laboratory
  notebook and its API. See its `documentation <https://doc.elabftw.net/>`_.
* `elabapi-python <https://github.com/elabftw/elabapi-python>`_ provides the
  generated Python API client used by eLabmate.
* `Labmate <https://github.com/kyrylo-gr/labmate>`_, by its upstream authors and
  contributors, provides the local acquisition and analysis workflow.
* NumPy and Matplotlib are used in the scientific examples. Sphinx produces
  this documentation.

These are separate projects with their own licences and maintainers. eLabmate
does not claim to be an official eLabFTW or Labmate product, nor to be endorsed
by either project. Its visual identity should be treated as eLabmate's own,
not as a replacement for either upstream logo.
