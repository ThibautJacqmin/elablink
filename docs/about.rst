Author, acknowledgements and scope
==================================

Author and maintainer
---------------------

**Thibaut Jacqmin** is the original author and maintainer of eLabLink. The
project grew from his laboratory code and requirements. Improvements, tests
and documentation have also received AI-assisted coding support under his
direction. The repository history records the actual contributions.

The MIT licence and copyright notices in the repository are authoritative.
Retain them when redistributing the project. eLabLink does not claim ownership
of its dependencies or change their licences.

Acknowledgements
----------------

* `eLabFTW <https://www.elabftw.net/>`_ provides the electronic laboratory
  notebook and its API.
* `elabapi-python <https://github.com/elabftw/elabapi-python>`_ provides the
  generated Python API client used by eLabLink.
* `Labmate <https://github.com/kyrylo-gr/labmate>`_ provides the local acquisition
  and analysis workflow.
* NumPy and Matplotlib are used in the scientific examples; Sphinx builds this
  documentation.

These projects have their own authors and licences. eLabLink is an independent
project, not an official eLabFTW or Labmate product and not an endorsement by
either project.

The notebook, atom and laser icon is eLabLink's own visual identity, developed
under Thibaut Jacqmin's direction with image-generation assistance. It does not
copy or replace the upstream logos; no legal clearance is implied.
